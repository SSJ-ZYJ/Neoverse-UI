# 中文术语与用词

Status: adopted

本文件约束 `README.zh-CN.md`、`packages/*/README.zh-CN.md` 与 `docs/zh-CN/` 的中文写法。代码标识符、包名、命令与官方产品名保持原样；需要解释时用中文概念，不重复英文全称。

## 术语

| 写法 | 含义 | 不使用 |
| --- | --- | --- |
| Neoverse-UI | 共享 UI 库的正文名称 | Neoverse UI、neoverse ui |
| 极光玻璃 | Aurora Glass，唯一的共享玻璃材质 | 玻璃材质（作专名时）、glass 材质 |
| 轻薄 / 标准 / 厚实 | 极光玻璃的三个层级 | 轻量级、等级、档位 |
| 表面 | `UiSurface` 等共享表面 | 面板、卡片（指表面时） |
| 浮层 | 运行时定位到顶层的界面 | 弹层、悬浮层 |
| 预设 | `glass-*` 等具名表面配方 | 变体、样式 |
| 样式变量 | 颜色、间距、时长等设计变量 | 令牌 |
| 组件规范 | 组件的状态、无障碍与交互规则 | 契约、协议 |
| 基础组件 | 终端、浮层等可组合的最小部件 | 原语 |
| 测试组件 / 测试页面 / 测试数据 | fixture 所代表的对象 | 夹具、fixture（代码标识符除外） |
| 消费项目 | 安装并使用共享包的仓库 | 消费方、用户 |
| 适配器 / 适配层 | Vue 或 React 的实现 | 封装、绑定层 |
| 样例 | Design Lab 中展示的组件状态 | 样本、演示 |
| 门禁 | 可执行的自动检查 | 质量门禁 |
| 基线 | 已确认的对照结果 | 基准线 |

## 用词

- 不写“落地”“沉淀”“闭环”“收口”“打通”“颗粒度”“心智”“体感”。
- 不写“强大”“极致”“无缝”“丝滑”“友好”“生态”“最佳实践”。写具体能力、条件或结果。
- 不写“若干”“大量”“一些”“等等”。写精确数量或完整枚举。
- 不写“值得注意的是”“总而言之”“综上所述”。直接写事实。
- 不写“赋能”“抓手”。写支持、提供、入口或具体措施。
- 英文词不接中文词缀。写“审查者”，不写“Review 者”。
- 能点名对象时写具体字段、文件、组件或流程，不写“体系”“形态”“叙事”。
- “对齐”只在能写出对齐对象和标准时使用，否则写“保持一致”。
- “编排”写动画、流程或具体动作；“装配”写创建、组装或注入。

## 维护

术语变化先改本文件，再同步受影响的中文页。英文源文件仍由 [docs/AGENTS.md](../AGENTS.md) 管；中文页与源文件的配对和哈希由 `docs/translations.json` 登记。
