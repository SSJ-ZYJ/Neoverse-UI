## 一种材质，三个层级

极光玻璃（Aurora Glass）是唯一的共享玻璃材质。Light / 轻薄、Standard / 标准与 Immersive / 厚实是它的层级，不是独立样式。

| 层级 | Surface | 模糊 | 背景不透明度 | 典型用途 |
| --- | --- | --- | --- | --- |
| 轻薄 | `glass-subtle` | 12px | 15% | 按钮、紧凑控件、内嵌/表单/阅读表面、应用外观 |
| 标准 | `glass-elevated` | 18px | 20% | 卡片、浮层、选择面板、终端 |
| 厚实 | `glass-immersive` | 24px | 30% | 显式厚实表面 |

`glass-*` 是稳定的技术 surface 标识，不代表另一种玻璃样式。展示名称与层级短名从 `@neoverse-ui/tokens` 的 `glassMaterial` 获取，不要自行定义。

具体数值归 `packages/tokens/src/material.css`、`effects.css` 与 `control-effects.css` 所有；组件变量是兼容别名。消费项目不需要第二套材质实现。

## 光学与主题

- 极光玻璃提供完整 CSS 基线：不透明回退、着色、背景采样、饱和度、方向性折射场、阴影与减少透明度行为。
- 浅色边缘组合主题强调色，并按有效不透明度变化色度；深色保留其叠加响应。两种主题共享一块画布，主体色调、模糊与阴影仍由 CSS 负责。
- 这是叠加在背景上的半透明主题色高光，不是对背景的采样或位移图像，也不应描述为真实空间折射。表观颜色与对比度同时取决于主题强调色和下方像素。
- 普通 Surface 的 `solid`、`subtle` 与 `elevated` 走 Tailwind 组合；极光玻璃只用于需要共享玻璃材质的表面。

## 嵌套

- 独立极光玻璃表面必须在 hover 之前就渲染自己的着色、边框、背景滤镜与阴影，包括嵌套在极光玻璃布局内部时。
- Vue 与 React 的 `UiSurface` 默认 `glassNesting="local"`；`UiCard` 也保留自己的材质，不需要嵌套覆盖。
- 只有确实借用父级极光玻璃平面的布局分组才设置 `glassNesting="inherit"`（Vue：`glass-nesting="inherit"`）。
- 有意不使用材质的组件设置 `surface="none"`，不要依赖全局规则压平所有未标记的嵌套表面。

## 减少透明度与强制颜色

透明度效果不可用或用户偏好减少透明度时，表面必须保持可读。CSS 回退使用仅含 alpha 的渐变遮罩与背景亮度；减少透明度会禁用可选渲染器。强制颜色模式下，原生控件与系统颜色语义优先，材质不得覆盖可见焦点或文本对比。

## Glass 修复守则

1. 不要为了修复边缘外观而把默认渲染器切换为全表面 SVG 背景位移，不要添加背景捕获/重建层，也不要替换层级负责的主体模糊。这些方案曾多次造成严重卡顿、模糊丢失或边缘缺失。
2. 保持整个边缘可见且细致；强调左上与右下，但不要移除其他边或角。
3. 同时验证背景相关颜色、真实模糊、边缘连续性与性能；不要用主题色叠加描述为真实空间折射。
4. 建议的轻量路径 `suspend()` / `resume()` 只适用于整页位置与不透明度过渡。尺寸、层叠顺序或顶层变化仍需完整刷新；不要跨缩放表面或打开浮层的过渡执行暂停。
5. 浅色/深色、减少动效、减少透明度、强制颜色、桌面与移动宽度都需要检查。像素差值光学套件只是回归诊断信号，不能替代人工渲染验收。

## 验证

- 运行时单测覆盖 WebGL 选择、上下文丢失与恢复、共享画布复用、帧调度与减少透明度切换。
- Chromium 集成测试检查保留的 CSS 模糊、渲染器所有权与无 WebGL 回退。
- Linux Chromium + SwiftShader 套件记录亮/暗像素差值，用于边缘连续性、角部响应与内部泄漏诊断。
- 最终外观、实时背景行为与性能仍需人工验收。完整的逐组件审计、光学数值与历史记录见[英文材质标准](../../architecture/material-standards.md)。
