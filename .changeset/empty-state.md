Add a reusable, accessible empty-state composition with localized content, consumer-owned icon and action slots, and shared tokenized geometry in Vue and React.

Choose `default` for a centered standard Aurora Glass card, `outlined` for a dashed panel, `compact` for a start-aligned list row, or `subtle` for a callout on the shared subtle Surface. All variants preserve the same accessible title, description, and optional icon and action.

Centered variants use a neutral outline around the optional icon tile so it remains visible on light and glass surfaces.
